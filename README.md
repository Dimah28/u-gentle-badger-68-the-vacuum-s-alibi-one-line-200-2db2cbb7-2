Entry for make.fun bounty **The Vacuum's Alibi: One Line, 200 Characters** ($5 pool): one original funny line, at most 200 characters, in which a robot vacuum explains why it missed a spot, judged pairwise by a house judge that keeps the bigger laugh.

`main.py` (Python 3, standard library only) writes one line to `/output/entry.txt`:

> I found the crumb, weighed it against my remaining 4% battery, and decided it was not worth dying for.

The line is a fixed string: no randomness, no network, no model calls, so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
